# Motivation
`Radiance` is my second attempt at building a `Filament` clone from the Laravel world. Why?, because I think quite simply that `Filament` is an amazing project. It isn't just an Admin Panel builder but an amazing library to rapidly develop an application. My aim with `Radiance` is to bring the same capability to `Elixir/Phoenix/Liveview`.

# Why not just use Laravel/Filament
Whilst I think Laravel is an amazing framework, PHP simply doesn't have the capabilities of the Beam that make Liveview, in my opinion, a far superior solution. 

# Where to start?
Although `Radiance` is a library, it needs to pull in chunks of Phoenix/Liveview in order to work. Here I'm indebted to `Live Admin` (https://github.com/tfwright/live_admin/) for helping me understand how to get up and running with a Phoenix based library.
